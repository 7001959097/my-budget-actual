My Budget vs Actual PWA v1.13

New: All 12 Dashboard summary cards are clickable. Each opens a popup with details for the currently selected month.
- Expense/Investment actual details support Edit and Delete.
- Budget and remaining-budget summaries show item-wise values.
- Advance summaries show outstanding received/paid amounts, including previous months, with original, adjusted and outstanding values.
- Daily Expenses, Total Transaction and Total Activities open their underlying records.

Existing localStorage key and data structure are retained. Take an in-app Backup before replacing files on GitHub Pages. Do not clear browser data.
After upload, refresh the app. If an older cached version appears, close and reopen the app or refresh once more so the updated service worker activates.
